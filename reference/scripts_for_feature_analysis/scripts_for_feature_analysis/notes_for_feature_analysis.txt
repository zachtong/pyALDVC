
Notes for the feature analysis scripts:

This folder contains Python scripts for quantitative feature analysis of 3D
volumetric images. The analysis pipeline uses autocorrelation (AC) functions to
estimate characteristic feature sizes and determine Representative Volume
Element (RVE) dimensions. The code was originally developed based on the
IMPPY3D framework (manuscript: https://joss.theoj.org/papers/10.21105/joss.07405,
code: https://github.com/usnistgov/imppy3d); see IMPPY3D_README.md and
IMPPY3D_LICENSE.txt in this directory for the original library documentation
and license terms.


Scripts:

 - acf_analysis.py is the core autocorrelation analysis module. It can be run
   as a standalone interactive tool:

     python acf_analysis.py

   The script prompts the user to select a 3D TIFF stack and an output
   directory via GUI dialogs, with options for layer cropping, spatial ROI
   selection, and denoising. It computes the 3D autocorrelation function
   using the Wiener-Khinchin theorem (FFT-based), extracts radially averaged
   correlation curves, and identifies characteristic length scales at three
   thresholds: 1/e (feature scale), 10% (mesoscale), and 1% (diagnostic).
   Outputs include SVG plots and .mat data files.

 - rve_analysis.py automates sweeping progressively larger ROI sizes to
   determine the minimum Representative Volume Element (RVE). It imports
   core functions from acf_analysis.py and is driven by JSON configuration
   files. Usage:

     python rve_analysis.py -c rve_configs/rve_config.json

   For each ROI size the script computes autocorrelation and characteristic
   lengths, then evaluates convergence using a sliding-window test with
   coefficient of variation (CV) and absolute tolerance criteria. Outputs
   include PNG figures, CSV summary tables, Markdown reports, and optional
   NPZ data archives.


Subfolders:

 - rve_configs/ contains over 40 JSON configuration files, one per dataset.
   Each config specifies ROI center, size schedule, convergence criteria, and
   correlation thresholds. The default template is rve_config.json.

 - evaluation_syn_img_generation/ contains two scripts for generating 3D
   synthetic sphere-packing volumes used for validation and evaluation of
   the autocorrelation analysis pipeline.

 - feature_analysis_results/ contains pre-computed autocorrelation analysis
   outputs (PDF and SVG figures) for 28 datasets. Each subdirectory is named
   to match the corresponding dataset directory under xct_data/, optical_data/,
   synthetic_data/, or nct_data/ in the bundle. When a dataset name appears in
   more than one data category (e.g., Notbohm_Fibrous exists in both
   optical_data/ and synthetic_data/), a modality suffix is appended to
   disambiguate (Notbohm_Fibrous_Confocal, Notbohm_Fibrous_Synth). One
   directory (Bay_Magma) contains results for a dataset whose raw data is not
   included in this bundle. Not every dataset in the bundle has a corresponding
   feature_analysis_results entry; only datasets for which autocorrelation
   analysis was performed are included here.


Setup:

  Install dependencies via Conda (recommended):
    conda env create -f environment.yml
    conda activate autocorrelation_env

  Or via pip:
    pip install -r requirements.txt

  Python >= 3.9 is required. See requirements.txt for the full dependency list.
